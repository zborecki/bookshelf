# Bookshelf

## Introduction
A backend system for managing the day-to-day operations of a library. The application provides a centralized catalog of books and authors, manages physical book copies, and handles the complete lending and return lifecycle.  

The system is built with C# and provides a RESTful API for external clients, along with an admin panel built with React for managing library data and monitoring its current status.
